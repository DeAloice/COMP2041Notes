## `echo`: print args to stdout
Useful Options:
![echoOptions](images/echoOptions.png)

```shell
echo Hello Andrew
Hello Andrew
$ echo '\n'
\n
$ echo -e '\n'
$ echo -n Hello Andrew
Hello Andrew
```

In Python:
```py
import sys
def main():
"""
print arguments to stdout
"""
print(' '.join(sys.argv[1:]))
```
